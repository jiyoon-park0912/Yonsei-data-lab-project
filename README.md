# Yonsei-data-lab-project
Yonsei data lab에 처음 입학한 학생을 위한 웹페이지를 제작하는 프로젝트입니다. 

## 메뉴 설명 

index.html : 맨 처음 main 페이지를 나타냅니다.   

data.html : Research Workflow에서 data 단계에 대한 설명이 담겨있습니다. 
idea.html : Research Workflow에서 Idea 단계에 대한 설명이 담긴 페이지입니다. 
literature.html : Research Workflow에서 Literature 단계의 설명이 담긴 페이지입니다. 
experiment.html : Research Workflow에서 Experiment 단계의 설명이 담겨있습니다. 
meeting.html : Research Workflow에서 Meeting 단계의 설명이 담겨있습니다. 
writing.html : Research Workflow에서 Writing 단계에 대한 설명이 있습니다.   

script.js: 체크리스트 진행률을 계산하고, 다크모드로 바꾸는 데 필요한 자바스크립트 코드입니다.   

style.css:홈페이지의 디자인을 꾸미는 역할을 하는 코드입니다. 코드가 깔끔하지 않으니 주의하세요.
