RESEARCH WORKFLOW · 04

Experiment

연구 질문에 맞는 모델을 구축하거나 데이터 분석을 수행하고, 분석 과정과 결과를 체계적으로 기록하는 단계입니다. 결과값만 남기는 것이 아니라 어떤 데이터와 설정을 사용했는지 함께 기록하는 것이 중요합니다.

1. Start from the Research Question

분석 방법은 먼저 정하고 연구 질문을 끼워 맞추는 것이 아니라, 연구 질문과 데이터의 특성에 맞게 선택해야 합니다.

  • 무엇을 설명하거나 예측하려는가?
  • 종속변수는 연속형인가, 범주형인가?
  • 비교하려는 집단이나 조건이 있는가?
  • 인과관계를 검토하려는가, 연관성을 확인하려는가?
  • 예측 성능이 중요한가, 변수의 해석이 중요한가?

2. Choose an Analysis Strategy

연구 목적에 따라 통계분석, 머신러닝, 자연어처리 등 적절한 분석 방법을 선택합니다.

Statistical Analysis

회귀분석, 분산분석, 로지스틱 회귀 등 변수 간 관계를 검토합니다.

Machine Learning

예측 문제에서는 여러 알고리즘을 비교하고 성능을 평가할 수 있습니다.

NLP

텍스트 분류, 임베딩, 토픽 분석 등 텍스트 데이터에 적합한 방법을 사용합니다.

Visualization

분포와 관계를 시각화해 데이터의 패턴과 분석 결과를 확인합니다.

3. Build a Baseline First

복잡한 모델을 바로 적용하기보다 먼저 단순한 기준 모델을 만들어두는 것이 좋습니다. 이후 모델의 성능이 실제로 개선되었는지 비교할 수 있기 때문입니다.

Example

이진 분류 문제라면 단순 로지스틱 회귀를 baseline으로 두고, Random Forest나 XGBoost 등의 결과와 비교할 수 있습니다.

4. Keep the Evaluation Fair

모델을 평가할 때는 분석 과정에서 데이터 누수나 과적합이 발생하지 않도록 주의해야 합니다.

  • 학습 데이터와 평가 데이터를 명확히 구분합니다.
  • 전처리는 가능한 한 학습 데이터 기준으로 수행합니다.
  • 모델 비교 시 동일한 데이터 분할과 평가 기준을 사용합니다.
  • 필요한 경우 Cross-validation을 사용합니다.
  • 연구 목적에 맞는 평가 지표를 선택합니다.

5. Use the Right Metrics

하나의 숫자만 보고 모델을 평가하지 말고, 연구 목적에 맞는 여러 지표를 함께 확인하는 것이 좋습니다.

Problem Metrics
Classification Accuracy, Precision, Recall, F1, ROC-AUC
Imbalanced Classification Precision, Recall, F1, PR-AUC
Regression MAE, RMSE, R²
Clustering Silhouette Score + 해석 가능성

6. Record Every Experiment

어떤 모델이 가장 좋았는지만 기록하지 말고, 각 실험에서 무엇을 바꿨고 결과가 어떻게 달라졌는지를 남겨두세요.

7. Save More Than the Final Number

최종 성능만 저장하면 나중에 왜 그 결과가 나왔는지 재현하기 어렵습니다. 분석 조건과 산출물도 함께 보관하세요.

  • 사용한 데이터 버전
  • 변수 목록과 전처리 방법
  • 모델 이름과 주요 파라미터
  • Random seed
  • 평가 지표
  • 그래프와 표
  • 실험 코드 버전

8. Interpret the Result

좋은 분석은 단순히 높은 성능이나 유의한 p-value를 보여주는 것으로 끝나지 않습니다. 결과가 연구 질문에 대해 무엇을 의미하는지 설명해야 합니다.

  • 어떤 결과가 가장 중요한가?
  • 처음 예상과 일치하는가?
  • 기존 연구와 비슷한가, 다른가?
  • 예상하지 못한 결과가 있다면 왜 그럴 수 있는가?
  • 모델의 한계와 해석상의 주의점은 무엇인가?

Checklist

  • 연구 질문에 맞는 분석 방법을 선택했는가?
  • 기준이 되는 baseline을 설정했는가?
  • 학습과 평가 과정이 적절히 분리되어 있는가?
  • 연구 목적에 맞는 평가 지표를 사용했는가?
  • 각 실험의 조건과 결과를 기록했는가?
  • Random seed와 데이터 버전을 기록했는가?
  • 결과를 연구 질문과 연결해 해석했는가?
